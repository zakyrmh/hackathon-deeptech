# Domain Glossary

| Istilah | Arti |
| --- | --- |
| Food Demand Intelligence | Inisiatif sistem pendukung keputusan untuk analisis pangan dan rekomendasi alokasi antardaerah |
| Rekomendasi | Hasil analisis untuk ditinjau manusia; bukan keputusan atau instruksi distribusi resmi |
| Intervensi distribusi | Opsi pemindahan pasokan antardaerah yang direkomendasikan untuk ditinjau; bukan pengiriman yang dieksekusi sistem |
| Analis Distribusi Pangan | Persona operator utama yang menjalankan analisis dan meninjau hasil |
| Penanggung jawab ketersediaan dan distribusi pangan | Persona pejabat yang menentukan tindak lanjut di luar sistem |
| Data publik | Data dari sumber terbuka/resmi yang provenance dan periodenya dicatat |
| Data operasional sintetis | Data stok, usia simpan, kapasitas, atau biaya buatan untuk demonstrasi dan berlabel non-aktual |
| Forecast tujuh hari | Prediksi harga harian dalam Rp/kg selama tujuh hari; bukan prediksi permintaan harian aktual |
| Tekanan pasar | Label turunan dari perubahan forecast harga; aturan ambangnya ditetapkan dalam SRS |
| Kebutuhan baseline | Estimasi kebutuhan yang diturunkan dari konsumsi dan populasi |
| Neraca wilayah MVP | `Stok sintetis + estimasi pasokan - kebutuhan baseline` |
| Surplus-defisit MVP | Nilai positif/negatif dari neraca wilayah; estimasi/skenario, bukan status operasional resmi |
| FEFO | Urutan penggunaan stok dengan tanggal kedaluwarsa terdekat lebih dahulu untuk semua komoditas |
| Prioritas tinggi cabai | Label untuk cabai merah keriting atau cabai rawit merah dengan sisa usia simpan kurang dari tiga hari |
| Skenario feasible | Skenario yang seluruh batas stok, kapasitas, anggaran, dan aturan terkaitnya terpenuhi |
| Prioritas optimizer | Kurangi defisit, prioritaskan stok terdekat kedaluwarsa, lalu minimalkan biaya; tetap tunduk pada seluruh constraint |
| Wilayah pilot MVP | Kabupaten Solok, Agam, Tanah Datar, Kota Padang, dan Bukittinggi sebagai simpul skenario demo |
